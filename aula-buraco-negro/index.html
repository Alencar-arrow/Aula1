PARTE 1 — HTML

HTML é o esqueleto da página

HTML (HyperText Markup Language) organiza o conteúdo em blocos chamados tags. Cada tag diz ao navegador "isto aqui é um título", "isto é um parágrafo", "isto é um link".

<a hrefatributoconfigura a tag="pagina.htmlvalorentre aspas">tag de aberturainício do elementoClique aquiconteúdoo que aparece na tela</a>tag de fechamentofim do elemento
<h1> a <h6>

Títulos, do mais importante (h1) ao menos importante (h6).

<p>

Um parágrafo de texto comum.

<a href="">

Um link para outra página ou site.

<img src="">

Uma imagem. Não tem tag de fechamento.

<ul> / <li>

Lista com itens: a lista, e cada item dentro dela.

<div>

Uma caixa genérica para agrupar e organizar outros elementos.

<span>

Uma caixinha genérica, mas para um trecho de texto.

<button>

Um botão clicável.

<br>

Quebra de linha. Sem tag de fechamento, assim como <img>.

<hr>

Uma linha horizontal, geralmente usada para separar seções de conteúdo.

<strong> / <em>

Texto em negrito (importância) e em itálico (ênfase).

<table>

Tabela com linhas <tr> e células <td>, para dados organizados em grade.

<form>

Agrupa campos que o usuário preenche e envia, como <input> e <button>.

<input>

Campo de entrada: texto, número, data, checkbox e outros tipos.

<label>

Rótulo de um campo de formulário, melhora acessibilidade e clique.

<header> / <footer>

Cabeçalho e rodapé semânticos de uma página ou seção.

<nav>

Agrupa os links de navegação principal do site.

<section>

Agrupa um bloco de conteúdo relacionado, com significado próprio na página.

<ol>

Lista de itens ordenadas.

Exemplo usando <br> para quebrar linhas dentro de um parágrafo, com texto "lorem ipsum" (um preenchedor clássico, sem significado, usado só para ocupar espaço):

Lorem ipsum dolor sit amet, consectetur adipiscing elit.<br> Sed do eiusmod tempor incididunt ut labore et dolore.<br> Ut enim ad minim veniam, quis nostrud exercitation.
PARTE 2 — CSS

CSS é a roupa da página

CSS (Cascading Style Sheets) escolhe um elemento HTML e diz como ele deve aparecer: cor, tamanho, espaçamento, posição. A receita é sempre a mesma: seletor + chaves + pares de propriedade: valor.

color

Cor do texto.

background

Cor ou imagem de fundo.

font-size

Tamanho do texto.

margin

Espaço fora da caixa, entre ela e as vizinhas.

padding

Espaço dentro da caixa, entre a borda e o conteúdo.

border

Contorno ao redor da caixa.

PARTE 3 — SELETORES

Três jeitos de apontar pra um elemento

O seletor decide quem recebe o estilo. Os três mais usados numa primeira aula:

p { }

Seletor de elemento — atinge todos os elementos daquele tipo na página.

<p>Este texto muda</p>
.destaque { }

Seletor de classe — atinge só os elementos com class="destaque". Pode repetir em vários.

<p class="destaque">Só este</p>
#titulo { }

Seletor de ID — atinge um único elemento, o dono daquele id. Não repete.

<h1 id="titulo">Único</h1>
PARTE 4 — BOX MODEL

Toda caixa tem quatro camadas

Todo elemento HTML vira uma caixa retangular na tela. Essa caixa sempre tem as mesmas quatro camadas, de dentro pra fora:

margin
border
padding
content

content

O conteúdo em si — texto ou imagem.

padding

Respiro interno, entre o conteúdo e a borda.

border

A linha que contorna a caixa.

margin

Respiro externo, entre a caixa e as vizinhas.
